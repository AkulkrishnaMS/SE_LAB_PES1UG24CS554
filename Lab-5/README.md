## Objective

To improve Python code quality, security, and style using static code analysis tools.

## Tools Used

- **Pylint:** Identifies code-quality issues and programming mistakes.
- **Bandit:** Identifies potential security vulnerabilities.
- **Flake8:** Checks Python formatting and PEP 8 style compliance.
